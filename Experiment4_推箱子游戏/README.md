    实验概述

程序主要由首页、游戏页面和关卡数据三个部分组成。

首页负责展示游戏名称、游戏说明以及四个可选择的游戏关卡；游戏页面负责完成地图绘制、角色移动、箱子推动、猪的消灭、步数统计、最佳成绩记录、撤销、重新开始、炸弹和游戏提示等功能；`data.js`则负责保存四个关卡的地图数据。

游戏的基本玩法：玩家控制小鸟在地图中移动，通过推动箱子撞击猪。当箱子被成功推到猪所在的位置时，箱子消灭猪。每局可以使用一次炸弹功能随机炸毁石头。每一步可以撤销或直接重开局，当所有猪都被消灭后，当前关卡通关。

​    主要功能包括：

1.  **首页展示功能**：显示游戏名称、游戏介绍和四个关卡。
2.  **卡通主题背景**：首页加入同一主题游戏背景图片。
3.  **关卡选择功能**：四个关卡可以从首页直接进入。
4.  **自定义关卡图片**：使用压缩包提供的图片。
5.  **游戏规则弹窗**：点击游戏说明可以查看详细规则。
6.  **Canvas 地图绘制**：使用 Canvas 根据地图数据绘制游戏场景。
7.  **小鸟移动**：支持上下左右方向按钮。
8.  **滑动控制**：支持手机屏幕滑动控制小鸟。
9.  **推箱子机制**：小鸟可以推动箱子。
10.  **猪的攻击机制**：不能直接走向猪，只能利用箱子撞击猪并消灭。
11.  **猪和箱子同时消失**：箱子撞到猪后，两者同时从地图中消失，原本猪的位置变回冰块。
12.  **剩余目标统计**：实时显示还需要消灭多少只猪。
13.  **通关判断**：所有猪消失后自动判断通关。
14.  **步数统计**：记录当前完成关卡的移动步数。
15.  **推箱次数统计**：记录玩家推动箱子的次数。
16.  **最佳成绩**：利用本地缓存保存每一关的最佳步数。
17.  **撤销功能**：可以恢复上一步的游戏状态。
18.  **重新开始**：可以重新挑战当前关卡。
19.  **炸弹技能**：每关可以使用一次炸弹炸开附近墙壁。
20.  **游戏提示**：每关设置多条提示，并随机显示。
21.  **下一关功能**：通关后可以直接进入下一关。
22.  **返回首页**：游戏过程中可以返回首页重新选择关卡。
