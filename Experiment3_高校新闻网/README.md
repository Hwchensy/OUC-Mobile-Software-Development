新闻资讯微信小程序

本项目是一个基于微信小程序开发的新闻资讯应用，主要包含首页、新闻详情页和个人中心页三个核心页面，并通过 tabBar 实现首页与个人中心之间的快速切换。

项目以新闻浏览为核心，同时加入了新闻搜索、轮播图、新闻详情、收藏、登录、账号管理、新闻分享、设置等功能，使整个小程序具有较完整的新闻资讯应用结构。

一、首页功能

首页是用户进入小程序后首先看到的页面，主要用于新闻展示和新闻浏览。

1. 新闻轮播图

首页顶部设置新闻轮播区域，通过微信小程序 swiper 组件实现幻灯片播放效果。

轮播图至少包含三张新闻图片，并设置自动播放和循环播放，使首页更加生动，同时可以在有限空间内展示多条重点新闻。

2. 新闻搜索

首页提供新闻搜索框，用户可以输入关键词查找新闻。

搜索功能基于实验提供的模拟新闻数据，通过遍历新闻标题并进行关键词匹配，实现本地搜索。用户输入关键词后，可以快速筛选出标题中包含该关键词的新闻，提高新闻查找效率。

3. 新闻分类

首页对新闻内容进行了简单的分类展示，例如学校新闻、媒体报道、校园活动等，使新闻内容具有更加清晰的层次。

用户可以通过不同分类快速定位自己感兴趣的新闻内容。

4. 热门新闻列表

首页下方设置新闻列表，展示新闻图片、新闻标题以及发布日期。

新闻数据统一由 common.js 管理，首页通过获取新闻列表数据动态生成新闻项目，因此不需要在 WXML 中逐条编写新闻内容。

5. 点击新闻查看全文

用户点击首页中的任意新闻后，可以进入对应的新闻详情页。

跳转时通过新闻的 id 作为参数传递给详情页面，再由详情页面根据 id 获取对应的新闻数据，从而保证点击不同新闻能够显示对应的内容。

二、新闻详情页功能

新闻详情页主要负责展示完整的新闻内容，是用户阅读新闻的主要页面。

1. 新闻详细信息

详情页完整显示：

新闻标题
新闻发布日期
新闻图片
新闻正文

页面采用较大的标题和清晰的正文排版，使新闻阅读更加方便。

2. 新闻收藏

详情页底部设置收藏按钮，用户可以点击按钮收藏当前新闻。

收藏状态使用本地缓存进行保存，每条新闻根据自身 id 生成对应的收藏标识。例如使用：

favorite_ + 新闻id

作为本地缓存的 key。

这样不同新闻之间的收藏数据可以相互区分。

3. 收藏状态变化

新闻未收藏时，按钮显示普通的收藏状态。

用户点击收藏以后，按钮会变成红色爱心和“已收藏”状态，表示当前新闻已经成功加入收藏夹。

再次点击后可以取消收藏，按钮恢复到未收藏状态。

这种设计通过视觉上的颜色和图标变化，让用户能够直接判断当前新闻是否已经收藏。

4. 登录限制

为了使收藏功能更加完整，项目设置了登录限制。

用户点击收藏时，程序首先读取本地保存的用户信息：

let userInfo = wx.getStorageSync('userInfo')

如果没有获取到用户信息，则说明用户还没有登录，此时不会直接收藏新闻，而是弹出提示。

用户可以选择**“去登录”**，程序会通过：

wx.switchTab({
    url: '../my/my'
})

直接跳转到个人中心页面。

这样形成了：

点击收藏 → 判断登录状态 → 未登录提示 → 跳转个人中心 → 登录 → 返回后继续使用收藏功能

的完整操作流程。

三、个人中心功能

个人中心是项目中功能比较集中的页面，主要负责用户登录、收藏管理和账号管理。

1. 用户登录

未登录时，个人中心显示默认头像、未登录状态以及“立即登录”按钮。

用户点击登录后，会出现登录窗口。

登录窗口不会直接自动获取用户信息，而是让用户主动进行操作：

点击按钮选择微信头像；
输入或选择自己的昵称；
点击“确定登录”。

头像通过微信小程序提供的 open-type="chooseAvatar" 实现，昵称通过昵称输入框获取。

确认登录以后，程序将用户头像和昵称保存到本地缓存中，并更新页面状态。

因此用户再次进入个人中心时，可以直接读取之前保存的信息。

2. 我的收藏

登录以后，个人中心会自动读取本地收藏数据，并显示收藏新闻列表。

程序通过遍历本地缓存中以 favorite_ 开头的数据，获取所有已经收藏的新闻。

收藏区域会显示：

收藏标题；
收藏数量；
新闻图片；
新闻标题；
新闻日期。

如果用户没有收藏任何新闻，则显示空收藏提示。

未登录时，收藏区域也不会显示收藏内容，而是提示用户登录后才能使用收藏功能。

3. 收藏新闻直接查看

收藏列表中的每条新闻都可以点击。

点击以后会携带新闻 id 跳转到新闻详情页，因此用户不需要重新从首页寻找新闻，可以直接阅读自己收藏的内容。

四、新闻分享功能

新闻详情页增加了分享功能，用户可以将当前正在阅读的新闻进行转发。

分享时以当前新闻的标题等信息作为分享内容，使用户可以把感兴趣的新闻推荐给其他用户。

分享功能与新闻详情页结合，使新闻从单纯的“阅读”扩展到了“阅读—收藏—分享”的完整使用流程。

五、账号管理功能

个人中心中增加了账号管理入口，用于管理当前用户的信息。

1. 修改个人信息

用户登录以后，可以进入账号管理，对自己的头像和昵称进行修改。

修改后的信息重新保存到本地缓存，并同步更新个人中心页面，使页面始终显示最新的用户信息。

2. 退出登录

账号管理中提供退出登录功能。

用户点击退出登录后，程序会弹出确认提示，避免用户误触。

确认退出后，只删除保存的用户登录信息：

wx.removeStorageSync('userInfo')

而收藏新闻等其他数据不会被删除。

因此重新登录后，之前的收藏内容仍然可以继续使用。

六、设置功能

个人中心中增加了独立的设置区域，主要包含清空收藏和关于新闻网等功能，使账号管理和应用设置相互区分，页面结构更加清晰。

1. 清空收藏

用户可以在设置中统一删除已经收藏的新闻。

点击清空收藏后，程序会先进行确认，用户确认以后才会删除所有以 favorite_ 开头的本地缓存数据。

清空完成后，收藏数量和收藏列表也会同步更新。

2. 关于新闻网

“关于新闻网”用于介绍当前新闻小程序的基本信息，使用户能够了解该应用的定位和基本情况。

通过单独设置“关于”内容，也避免将过多信息直接堆放在个人中心首页，使页面保持简洁。

七、本地数据管理

项目没有使用服务器数据库，而是使用微信小程序提供的本地缓存功能保存用户相关数据。

主要包括：

userInfo：保存用户头像和昵称；
favorite_新闻id：保存收藏的新闻；
新闻数据：由 common.js 中的模拟数据统一管理。
