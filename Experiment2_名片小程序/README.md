名片小程序
一、项目简介

本项目为中国海洋大学《移动软件开发》课程实验制作的微信小程序个人名片。

本项目以个人信息展示为核心。页面主要采用浅蓝色作为背景色，结合白色卡片和深蓝色重点模块。

页面展示个人基本信息，以及专业介绍、学习方向、校园经历、兴趣爱好、个人关键词和联系方式等内容，实现了邮箱复制功能。

二、页面主要功能
1. 个人信息展示

页面顶部使用个人名片，并展示姓名、学校、学部和专业等基本信息。

2. 关于我

通过文字介绍个人基本情况、专业背景以及对计算机技术的兴趣，同时介绍大学期间的学习目标和实践方向。

3. 我的专业

重点介绍计算机科学与技术专业，并从程序设计、数据结构、算法和软件开发四个方面进行展开。通过卡片布局将不同专业内容进行分类。

4. 我的学习方向

展示个人目前的主要学习方向，包括编程基础、算法与数据结构、软件开发以及新技术探索，体现个人的学习规划。

5. 校园经历

使用时间轴形式展示大学阶段的学习过程，从进入中国海洋大学开始，到专业课程学习、课程实践以及未来持续探索。

6. 兴趣爱好

介绍旅游、摄影和滑雪三个兴趣爱好，通过图形、标题和文字描述相结合的方式展示。

7. 我的关键词

通过标签形式对个人特点进行总结。

8. 联系我

页面底部设置联系方式，展示个人姓名、学校、专业、电话号码、邮箱和地址，提供邮箱复制功能。

9. 邮箱复制

用户点击“复制我的邮箱”按钮后，可以将页面中的邮箱直接复制到系统剪贴板。复制成功或失败后都会通过反馈。
