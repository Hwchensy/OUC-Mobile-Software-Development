# 实验1：热身运动

## 一、实验简介

本实验是《移动软件开发》课程的第一次实验，主要用于熟悉微信小程序的基本开发流程和开发工具的使用。

本实验设计并实现了一个简单的猫咪主题微信小程序页面，页面包含文字、表情、猫咪图片和按钮等基本元素，并通过 JavaScript 实现页面内容的动态切换。

## 二、实验功能

本实验主要实现了以下功能：

- 设置微信小程序基本页面结构；
- 显示 `hello girl!` 和 `hello boy!` 两种状态；
- 根据当前状态动态显示 👧 或 👦 图标；
- 显示一张猫咪图片；
- 设置黄色圆角按钮；
- 点击按钮后在 `girl` 和 `boy` 两种状态之间进行切换；
- 增加文字和表情的缩小淡出、放大淡入动画；
- 增加按钮点击时的缩小和透明效果。

## 三、开发环境

- 开发工具：微信开发者工具
- 开发语言：WXML、WXSS、JavaScript
- 页面框架：微信小程序原生开发

## 四、主要技术

### 1. WXML

使用 WXML 搭建页面结构，通过 `view`、`text`、`image` 和 `button` 等组件完成页面布局，并使用数据绑定和条件渲染实现动态内容。

### 2. JavaScript

使用 `Page` 定义页面，通过 `data` 保存页面状态，并使用 `setData()` 修改数据。通过 `bindtap` 绑定按钮点击事件，实现 `girl` 和 `boy` 两种状态之间的切换。

### 3. WXSS

使用 WXSS 设置页面的字体、颜色、间距、圆角、阴影等样式，并通过 `@keyframes` 实现文字和表情的缩放、淡入和淡出动画。
